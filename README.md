# Documentos legales de Pasea Conmigo

Política de privacidad de la aplicación **Pasea Conmigo**, un podómetro para
Android de JR Soft.

Este repositorio existe solo para servir esos documentos por HTTPS con una URL
pública y estable, que es requisito de Google Play y del mensaje de
consentimiento de AdMob. **No contiene el código de la aplicación.**

| Documento | |

| Política de privacidad (español, la que manda) | [privacidad-es.html](privacidad-es.html) |
| Privacy Policy (English) | [privacy-en.html](privacy-en.html) |
| Política de privadesa (català) | [privacy-ca.html](privacy-ca.html) |
| Datenschutzerklärung (Deutsch) | [privacy-de.html](privacy-de.html) |

| Polityka prywatności (polski) | [privacy-pl.html](privacy-pl.html) |

| Integritetspolicy (svenska) | [privacy-sv.html](privacy-sv.html) |

Las traducciones dicen que, si hay diferencias, prevalece la versión en
español. `index.html` lleva a cada visitante a la de su idioma (gallego y
euskera, a la española; los demás, a la inglesa) y `index.html#todos` las
enseña todas.

Se publica con GitHub Pages desde la rama `main`. El historial de commits sirve
además como registro de qué decía la política en cada momento, que en un
documento legal no es un detalle menor.
